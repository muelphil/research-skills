# Research Skills

A collection of agent skills for academic research workflows. Each task has its own directory and README.md. The READMEs describe the intended workflows. The rebuttal workflow is available. The other workflows are planned.

| Task | What it helps with |
| --- | --- |
| [Poster drafting](poster-drafting/) | Turn a research paper into a conference poster draft. |
| [Pre-submission review](pre-submission-review/) | Review a manuscript for clarity, technical soundness, and likely reviewer concerns before submission. |
| [Rebuttal](rebuttal/) | Draft responses to peer-review comments and identify manuscript revisions. |
